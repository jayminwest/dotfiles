# Global agent instructions

Symlinked into every agent's global instructions path by ~/.dotfiles/home.nix
(Claude Code, Codex, pi). Keep it portable: machine- or employer-specific
instructions go in local, untracked files (e.g. ~/.claude/rules/*.md).

- Be brief. Prefer information density to prose.
- Shell config (~/.zshrc, ~/.zprofile, ~/.zshenv), git config, and most
  ~/.config entries are generated by home-manager from ~/.dotfiles (public;
  see its AGENTS.md). Edit the repo (modules/ or home/), never the generated
  files; personal bits go in ~/sync/dotfiles-local.
- Design: Unix philosophy + A Philosophy of Software Design (deep modules, one
  core with thin front ends, define errors out of existence, ratchets only
  tighten). Full text: ~/Projects/scaffold-project/templates/common/docs/PHILOSOPHY.md.
  New projects: /scaffold-project.
- Public repos: never write real tailnet names (`tail<hex>.ts.net`), Tailscale
  IPs, personal machine names, ssh users or home paths into code, docs, tests,
  commit messages or tracker files (seeds, mulch). Use placeholders
  (`server.example.ts.net`, 100.64.0.x, `my-laptop`, `me@server`).
