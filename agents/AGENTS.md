# Global agent instructions

Symlinked into every agent's global instructions path by ~/.dotfiles/home.nix
(Claude Code, Codex, pi). Keep it portable: machine- or employer-specific
instructions go in local, untracked files (e.g. ~/.claude/rules/*.md).

- Be brief. Prefer information density to prose.
- Shell config (~/.zshrc, ~/.zprofile, ~/.zshenv), git config, and most
  ~/.config entries are generated by home-manager from ~/.dotfiles. Edit the
  repo (home.nix or home/), never the generated files.
